# Changelog

## 0.1.0 — public release preparation

The public repository starts with fresh release history. `main` contains the
macOS release; `windows-version` contains the Windows tray/VirtualBox variant.

- Local-first desktop automation through MCP, CLI, and the browser Control Room.
- External model bridges, cooperative task controls, and workflow memory/replay.
- Windows system tray controls and managed VirtualBox Windows guest setup.
- Branch-specific installation instructions and links to the public repository.
- Complete allowlisted source packages, including active Stocks/Weather example
  records and their target crops. Shared videos and branding remain linked from `main`.
- Deprecated Clock examples, local test folders, and retired developer/benchmark
  material excluded from release trees and packages.
- Automated source-package checks and fresh-package MCP smoke verification.

Release preparation does not establish a performance benchmark. The demo videos
show planned tasks; they do not validate replay savings. Native app permissions,
fresh-desktop replay, and full VM creation require the manual checks in
[RELEASE.md](RELEASE.md) before publication.

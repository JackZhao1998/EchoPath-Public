# Artifact Notes

The current Stocks, Clock, and Weather examples do not need starter files. They use local macOS apps
and public or built-in app data already available on the device.

The packaged crop assets live under:

- `../../memory/consolidated/crops/local-demo-stocks-amazon-1w-close/`
- `../../memory/consolidated/crops/local-demo-clock-timer-000015-close/`
- `../../memory/consolidated/crops/local-demo-weather-location-forecast-close/`

They are small screenshots of stable UI targets, not full desktop captures. The Clock timer duration
fields are dynamic keyboard inputs, while the Timer tab and Start button use saved target icons. The
Weather location is a dynamic text input, while the Weather search field uses a saved target icon.
